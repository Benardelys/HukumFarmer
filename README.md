**Advanced Farmer Plugin for Minecraft**

## Farmer System

Players do not receive an active farmer immediately after purchasing one.

The purchase flow works like this:

```text
Open Farmer Menu
       ↓
Purchase Farmer
       ↓
Pay the configured price
       ↓
Receive Farmer Egg
       ↓
Choose a location
       ↓
Place Farmer Egg
       ↓
Farmer is created
       ↓
Farmer NPC is created
```

This allows players to decide exactly where they want their farmer to be placed.

---

## Farmer Egg

The Farmer Egg is a secure custom item generated by HukumFarmer.

The item can be configured with:

* Material
* Display name
* Lore
* Glow
* Custom Model Data
* Player Head texture
* ItemsAdder custom item
* Language-specific text

Farmer Eggs are identified using a secure `PersistentDataContainer` value rather than relying only on item names or lore.

This prevents players from creating fake Farmer Eggs by renaming ordinary Minecraft items.

## ItemsAdder Support

HukumFarmer provides optional ItemsAdder integration.

Example configuration:

```yaml
farmer-item:
  itemsadder:
    enabled: true
    item-id: "hukumfarmer:farmer_egg"
```

If ItemsAdder is installed and the configured item exists, HukumFarmer can use the custom ItemsAdder item.

If ItemsAdder is unavailable or the configured item cannot be found, HukumFarmer safely falls back to the configured Bukkit item.

ItemsAdder is optional and is not required to run HukumFarmer.

## Multilingual System

HukumFarmer includes a per-player language system.

Supported languages:

* Turkish
* English
* German
* French
* Spanish
* Russian

Language files:

```text
languages/
├── tr.yml
├── en.yml
├── de.yml
├── fr.yml
├── es.yml
└── ru.yml
```

Each player can select their own language.

For example:

```text
Player A → English
Player B → Turkish
Player C → German
```

Changing one player's language does not affect other players.

Language selections are saved and restored after reconnecting or restarting the server.

## Installation

1. Download the latest HukumFarmer `.jar`.
2. Place the file into your server's:

```text
plugins/
```

directory.

3. Install Vault and your preferred economy provider if required by your configuration.
4. Install optional dependencies such as ItemsAdder, AxMinions or WorldGuard if you want their integrations.
5. Restart the server.
6. Configure HukumFarmer inside:

```text
plugins/HukumFarmer/
```

7. Restart the server again after configuration changes if required.
