# HukumFarmer

**Advanced Farmer Plugin for Minecraft**

HukumFarmer is a powerful and configurable farmer management plugin designed for modern Paper servers. It provides a complete farmer system with a graphical interface, farmer eggs, NPC integration, economy support, multilingual messages, ItemsAdder compatibility, AxMinions integration and strong protection against common exploits.

## Farmer System

Players do not receive an active farmer immediately after purchasing one.

The purchase flow works like this:

```text
Open Farmer Menu
       ↓
Purchase Farmer
       ↓
Pay the configured price
       ↓
Receive Farmer Egg
       ↓
Choose a location
       ↓
Place Farmer Egg
       ↓
Farmer is created
       ↓
Farmer NPC is created
```

This allows players to decide exactly where they want their farmer to be placed.

---

## Farmer Egg

The Farmer Egg is a secure custom item generated by HukumFarmer.

The item can be configured with:

* Material
* Display name
* Lore
* Glow
* Custom Model Data
* Player Head texture
* ItemsAdder custom item
* Language-specific text

Farmer Eggs are identified using a secure `PersistentDataContainer` value rather than relying only on item names or lore.

This prevents players from creating fake Farmer Eggs by renaming ordinary Minecraft items.
